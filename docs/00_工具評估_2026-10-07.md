# 工具評估（2026-10-07）

需求：想法分散在 ChatGPT、Claude、Kimi 等工具，需要一個能追蹤的系統。

## 結論

不找單一工具，而是三層架構：單一真相來源 + 擷取 + 回查。

| 層 | 選擇 | 理由 |
|---|---|---|
| 儲存 | Obsidian（Markdown，iCloud 同步） | 不被任何 AI 廠商綁住 |
| 擷取 | 瀏覽器擴充 | 少數能涵蓋 Kimi 的方式 |
| 回查 | Basic Memory（MCP） | 讓 Claude、ChatGPT 讀寫本機 Markdown 知識庫 |

## 評估過的選項

- **Chat2Note**：開源瀏覽器擴充，可從 ChatGPT、Claude、Kimi 等匯出到 Obsidian／Notion。手動點擊，不符合後來的「無痕」需求，因此改為自寫擴充。
- **Basic Memory**：MCP server，讀寫本機 Markdown，可接 Obsidian。保留為回查層。
- **MemoryPlugin**：付費（Core $89／年、Pro $180／年），透過擴充支援 Kimi；只存關鍵事實、不存完整對話，歷史匯入不含 Kimi，資料在第三方。未採用。
- **Notion 當 Inbox**：最省事，但資料在雲端、與本地 LLM 整合弱。備選。

## 後續演進

2026-10-15 需求升級為「無痕、一次性設定、記錄互動平台」，見 `2026-10-15_IdeaLedger_設計文件_v1.html`。
