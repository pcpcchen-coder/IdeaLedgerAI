## 目標

把 `summary` 表寫成 Obsidian 想法卡，並產生每日平台互動日誌。在 `python -m summarizer` 摘要完成後接著執行。

## 範圍：`summarizer/obsidian.py`

### 想法卡

- 路徑：`<vault>/Ideas/YYYY/MM/YYYY-MM-DD_<platform>_<標題>.md`，日期取對話**建立時間**（本地時區，預設 Asia/Taipei），所以同一段對話的檔名日期不會變。
- 標題含 `/ \ : * ? " < > |` 等字元時替換，最長 60 字。
- 重新摘要後標題改變 → 搬到新檔名、刪除舊檔（以 `card` 表記錄每段對話目前的路徑）。
- **保留使用者的修改：**
  - frontmatter 的 `status`（inbox／探索中／立項／封存）由使用者手動改，重寫時沿用。
  - 檔案中 `<!-- 以下為個人筆記，系統不會覆寫 -->` 之後的內容原樣保留。
- 只在摘要有更新時重寫；沒有變化不碰檔案。
- 寫檔用暫存檔再取代，避免 Obsidian 讀到寫一半的檔案。

### 每日平台互動日誌

- 路徑：`<vault>/Ideas/_log/YYYY-MM-DD.md`，依對話**最後更新時間**歸日（本地時區）。
- 第一行：各平台巡檢狀態（取每個平台最近一次 `sweep_run`）。
- 表格：時間、平台、對話（有想法卡就連結，還沒摘要標「摘要中」）、專案。
- 每次執行重寫「今天」與「本次有想法卡更新的日子」。

### 設定

`IDEA_VAULT`（Obsidian vault 根目錄；未設定就不寫）、`IDEA_TZ`（預設 `Asia/Taipei`）。

## 驗收（pytest，暫存資料夾當 vault）

- [x] 想法卡內容與預期快照完全一致
- [x] 檔名日期依本地時區（UTC 17:00 → 台北隔天）；不合法字元被替換
- [x] 使用者改過的 `status` 與個人筆記在重寫後保留
- [x] 標題變更 → 新檔出現、舊檔刪除
- [x] 沒有新摘要時再執行一次不改動任何檔案（日誌內容相同也不重寫，連修改時間都不變）
- [x] 日誌第一行列出各平台狀態；未摘要的對話標「摘要中」；新平台以顯示名稱出現
- [x] `make test` 全過
