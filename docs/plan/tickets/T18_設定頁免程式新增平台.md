## 目標

不寫程式也能加入新的 AI 平台（例如 Gemini、Grok）：在設定頁填名稱、網域、對話網址規則，之後在這個瀏覽器打開該平台的對話，頁面靜止 20 秒就擷取純文字送 collector（`capture="page"`），照常摘要成想法卡。

## 開工前讀

- `docs/ADDING_A_PLATFORM.md`「方式二」
- `extension/legacy/capture.js`（v1 頁面擷取邏輯）
- `collector/app/models.py`（`capture="page"`、`page_text`、`platform_name`）
- `extension/build.config.mjs`、`manifest.base.json`、`src/options/`

## 範圍

### 自訂平台（`src/lib/custom-platforms.js`，純函式）

- 輸入：顯示名稱、網域（不含 `https://` 與路徑）、對話網址規則（正規式，第一個括號取對話 ID）。
- 平台 id 由名稱產生（小寫英數與連字號；中文等無法轉換時用 `custom`），符合 `^[a-z][a-z0-9-]{1,31}$`，並避開已註冊 adapter 與其他自訂平台的 id（加 `-2`、`-3`）。
- 檢查：名稱非空；網域格式正確且不與任何平台重複；規則是合法正規式且至少一個括號。

### 註冊與移除（`src/bg/custom.js`，注入 chrome API 以便測試）

- 新增：`chrome.permissions.request` 要該網域權限 → 被拒則不儲存 → `chrome.scripting.registerContentScripts` 注入通用擷取腳本 → 存 `chrome.storage.local` 的 `customPlatforms`。
- 移除：解除注入 → 收回權限 → 刪除設定（collector 中已收的資料不動）。
- 背景程式啟動時對齊：已存的自訂平台若沒有注入就補上，沒有對應設定的注入就移除。
- manifest 加 `optional_host_permissions: ["https://*/*"]` 與 `scripting` 權限（`manifest.base.json` 允許為此修改一次；之後新增平台都不需要改）。

### 通用擷取腳本（`src/content/page-capture.js`）

- 沿用 v1：DOM 變動停止 20 秒、或分頁切到背景時擷取；`main`（沒有就 `body`）的 `innerText`；同內容不重送；文字太短（< 200 字）不送。
- 網址不符合對話規則、臨時對話（網址含 `temporary`）、文字含 `#nolog` → 不送（不讓文字離開頁面）。
- 平台設定向背景程式查詢；背景程式以**分頁網域**判斷平台，不信任訊息中的平台欄位。

### 送出（背景程式）

- `{ platform, platform_name, capture: "page", conv_id, title, url, project: null, created_at, updated_at, page_text, swept_at, sweeper }`。
- `created_at` 用第一次擷取到這段對話的時間（存起來，之後不變，想法卡檔名才穩定）；`updated_at` 用擷取時間。
- collector 連不上時放進待送佇列（同一對話只留最新一份），下一輪巡檢前補送。

### 設定頁

- 「自訂平台（頁面擷取）」區：名稱、網域、規則三欄＋新增按鈕；已加入的列表含刪除按鈕與最後擷取時間。

## 驗收（node:test，以假網域與假 chrome API）

- [ ] 新增：權限被要求、腳本被注入、設定被儲存；id 由名稱產生
- [ ] 權限被拒：不注入、不儲存，回傳清楚的錯誤
- [ ] id 衝突：與內建平台或其他自訂平台同名時自動加尾碼；網域重複時拒絕
- [ ] 刪除：解除注入、收回權限、刪除設定
- [ ] 啟動對齊：補注入缺的、移除多的
- [ ] 擷取：對話 ID 取自網址；臨時對話、`#nolog`、太短、規則不符時不送；送出的內容符合 collector 格式（`capture="page"`），`created_at` 第一次擷取後固定
- [ ] 背景程式以分頁網域決定平台，訊息偽造的平台被忽略
- [ ] 除了 `manifest.base.json` 一次性加入權限，不需要修改 adapters 或核心程式即可新增平台
- [ ] 設定頁可新增、刪除自訂平台（Playwright 載入 `dist/` 確認畫面）
- [ ] `make test` 全過
