## 範圍

### `adapters/chatgpt/fetch.js`、`adapters/claude/fetch.js`

實作固定介面 `checkLogin()`、`listUpdated(cursor)`、`getConversation(id)`：

- 一律同源 `fetch`，`credentials: "include"`，**只用 GET**。
- 需要的權杖或組織 ID 在分頁存活期間快取，401 時清除快取重取一次。
- HTTP 狀態對應錯誤類型（`src/lib/errors.js`）：401 → `NeedsLogin`；403、429 → `RateLimited`；解析失敗 → `AdapterFormatError`。
- 取得回應後交給 parse.js，不在這裡解析。

### 設定頁 `options/`

- 欄位：collector 網址（預設 `http://127.0.0.1:8787`）、token、巡檢間隔（15–120 分）、節點名稱（預設 `mac-mini`）、巡檢開關。
- 「立即巡檢」按鈕。
- 每平台狀態：燈號、最後成功時間、上輪抓取數、錯誤訊息。平台列表由 `registeredPlatforms()` 動態產生，顯示 `platform.json` 的 `name`，不寫死。
- 每個平台可個別開關巡檢（存在 `chrome.storage`），預設開啟。
- 擴充圖示徽章：全綠無字；有黃燈顯示 `!`（黃）；有紅燈顯示 `!`（紅）。
