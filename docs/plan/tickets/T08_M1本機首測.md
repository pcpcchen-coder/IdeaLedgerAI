## 目標

在真實環境驗證 M1：擴充用你的登入狀態讀到 ChatGPT、Claude 的對話（包含手機 App 上的），並寫進 collector。

可以先在你自己的 Mac 上測，不必等 Mac Mini 部署（T11）。

## 需要

Git、Node 20+、Python 3.12+、Chrome。

## 步驟

1. **取得最新程式並建置**
   ```bash
   git pull
   make build
   ```
2. **啟動 collector**（另開一個終端機，保持執行）
   ```bash
   cd collector
   pip install -r requirements.txt
   IDEA_TOKEN=自訂一串亂碼 uvicorn app.main:app --host 127.0.0.1 --port 8787
   ```
3. **建立專用 Chrome 設定檔**：Chrome 右上角頭像 → 新增 → 命名「IdeaLedger」→ 登入 chatgpt.com 與 claude.ai。
4. **載入擴充**：在該設定檔開 `chrome://extensions` → 右上開啟「開發人員模式」→「載入未封裝項目」→ 選 `extension/dist`。
5. **設定**：擴充的「選項」頁 → 填 token（與第 2 步相同）→ 儲存 → 按「立即巡檢」。
6. **看結果**：設定頁兩個平台應轉綠燈。查資料庫：
   ```bash
   sqlite3 collector/ledger.db "select platform, title, updated_at, message_count from conv order by updated_at desc limit 10"
   ```
7. **測 App 同步**：在手機 App 對 ChatGPT、Claude 各聊一句新的，等 10 分鐘後再按一次「立即巡檢」，確認兩段都出現。

## 出問題時

- 打開 `chrome://extensions` → 本擴充的「Service Worker」→ Console，複製錯誤訊息。
- 開一個雲端工作階段，貼上錯誤訊息並說「T08 首測失敗」，由雲端工作階段開修正工單。
