## 設計

**放在哪裡：collector 自己提供網頁（`http://127.0.0.1:8787/ui`）。** 對話全文只在 Mac Mini 本機資料庫，不進任何 repo；由 collector 同一個程序讀資料庫、同一個 port 提供頁面，不必多開服務，也不必把資料搬出本機。只綁 127.0.0.1，不對外。

**驗證：靜態頁不含資料、不需 token；資料一律走需要 Bearer token 的 `/v2` API。**
- 頁面第一次開啟時從網址片段 `#token=…` 讀 token（片段不會送到伺服器），存進該瀏覽器的 localStorage，並立刻從網址移除。
- 入口：選單列圖示「瀏覽對話紀錄…」（預設瀏覽器）與擴充設定頁「瀏覽紀錄」（巡檢用的 Chrome 設定檔；在這裡點「開啟原對話」，平台已是登入狀態）。兩者都自動帶 token。
- 直接打網址時頁面會請你輸入一次 token。
- 其他網站讀不到資料：API 需要 token、沒有 CORS 標頭；token 存在 127.0.0.1:8787 這個來源的 localStorage，別的網站拿不到。

**API（全部唯讀、`Cache-Control: no-store`）**

| 端點 | 用途 |
|---|---|
| `GET /v2/conversations?q=&platform=&project=&limit=&offset=` | 清單與搜尋。依最後更新時間由新到舊；回傳總數、片段與片段的發言者 |
| `GET /v2/conversations/{platform}/{conv_id}` | 單篇全文（含頁面擷取）、想法卡路徑 |
| `GET /v2/facets` | 篩選選項：平台與筆數、專案與筆數、不在專案內的筆數 |

**搜尋**
- 子字串比對（`LIKE`），範圍：標題、專案名稱、所有訊息（使用者與 AI）、頁面擷取文字。空白分隔多個詞＝全部都要出現。英文不分大小寫。`%`、`_`、引號照字面比對。
- 不用 FTS5：中文沒有空白斷詞，FTS5 預設斷詞器會把整句當一個詞，反而找不到。幾千篇全表掃描仍在百毫秒內；資料量大到變慢再換 FTS5 trigram。
- 篩選：平台、專案（含「不在專案內」）。選項全部來自資料，不寫死平台。

**介面**
- 左欄清單：平台、專案、更新時間、標題、片段（命中詞標黃；命中在 AI 回覆時標「AI：」）、`↗` 直接到平台開原對話。
- 右欄全文：標題、平台／專案／時間／則數、「在〈平台〉開啟原對話 ↗」、複製網址、「只看我的輸入」、本篇命中數；自動捲到第一個命中處；顯示 AiMemory 想法卡路徑（若已產生）。
- 網址記住搜尋詞、篩選與目前對話（`#q=…&p=…&proj=…&c=平台/id`），重新整理不會遺失。
- 快捷鍵：`/` 搜尋、`↑` `↓` 選擇、`Enter` 開啟、`O` 到平台開原對話、`Esc` 返回。
- 淺色／深色跟隨系統；窄螢幕一次顯示一欄。

**安全**
- 對話內容一律以文字節點呈現，不把任何字串當 HTML 解析（對話裡可能有程式碼或 HTML）。
- 外部連結只接受 http(s)，以 `noopener noreferrer` 開新分頁。
- CSP：只准載入自己的腳本與樣式、只准連回 collector、禁止被嵌入；`Referrer-Policy: no-referrer`。
- 靜態檔以白名單提供，不從路徑組檔名。
