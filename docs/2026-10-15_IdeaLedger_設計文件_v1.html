Idea Ledger：跨平台 AI 對話自動記錄系統

設計文件 v1 · 2026-10-15 · 適用 ChatGPT / Claude / Kimi（可擴充）

結論：「寫進各平台預設 prompt／skill」做不到真正無痕，改在瀏覽器層被動擷取，由 Mac Mini 本地模型摘要後寫入 Obsidian。 一次設定後，對話中不需任何操作、不留任何額外文字或工具呼叫，且每筆紀錄自帶「平台、時間、連結」。

1. 為什麼不用 prompt／skill 方案

需求Prompt／Skill 方案瀏覽器被動擷取
無痕✗ 寫入必須是可見的工具呼叫；ChatGPT 寫入動作還建議逐次確認✓ 對話內容零改變
全平台✗ 模型要有寫入工具才能記錄；Kimi 網頁版查不到可設定的寫入管道；ChatGPT 自訂連接器需開發者模式，且連不到 localhost✓ 只要是網頁就能抓
可靠✗ 依賴模型遵從率，漏記無法察覺✓ 確定性程式，失敗可重試
一次設定✗ 3 個平台各設一次，平台改版要重設✓ 一個擴充 + 一個服務

2. 架構

ChatGPT / Claude / Kimi 網頁→ 擴充 capture.js
對話靜止 20 秒時擷取→ bg.js 離線佇列→ HTTPS + Token → Mac Mini Collector
FastAPI + SQLite→ Summarizer
LiteLLM → Ollama→ Obsidian vault
iCloud 同步
  • 擷取不解析訊息結構：只抓 main 的純文字，交給 LLM 理解。平台改版時只要網址規則沒變就不會壞，比逐一解析 DOM 穩定得多。
  • 摘要在本機：EMS、電池等公司內容不經第三方雲端。
  • 延遲摘要：對話 15 分鐘沒有新內容才摘要，避免聊到一半反覆重算。

4. 元件規格

4.1 瀏覽器擴充（MV3，約 80 行）

// manifest.json
{
  "manifest_version": 3,
  "name": "Idea Ledger Capture",
  "version": "0.1.0",
  "permissions": ["storage", "alarms", "unlimitedStorage"],
  "host_permissions": ["https://ideas.YOUR-DOMAIN/*"],
  "background": { "service_worker": "bg.js" },
  "content_scripts": [{
    "matches": ["https://chatgpt.com/*", "https://claude.ai/*",
                "https://www.kimi.com/*", "https://kimi.moonshot.cn/*"],
    "js": ["capture.js"], "run_at": "document_idle"
  }]
}
// capture.js — 新增平台只要加一行 adapter
const ADAPTERS = {
  "chatgpt.com":      { platform: "chatgpt", id: /\/c\/([\w-]+)/ },
  "claude.ai":        { platform: "claude",  id: /\/chat\/([\w-]+)/ },
  "www.kimi.com":     { platform: "kimi",    id: /\/chat\/([\w-]+)/ },
  "kimi.moonshot.cn": { platform: "kimi",    id: /\/chat\/([\w-]+)/ },
};
const A = ADAPTERS[location.hostname];
let timer, lastHash = "";

async function sha(s) {
  const b = await crypto.subtle.digest("SHA-256", new TextEncoder().encode(s));
  return [...new Uint8Array(b)].map(x => x.toString(16).padStart(2, "0")).join("");
}

async function flush() {
  const m = location.pathname.match(A.id);
  if (!m || location.search.includes("temporary")) return;   // 臨時對話不記
  const text = (document.querySelector("main") || document.body).innerText.trim();
  if (text.length < 200 || text.includes("#nolog")) return;   // 太短或手動排除
  const hash = await sha(text);
  if (hash === lastHash) return;
  lastHash = hash;
  chrome.runtime.sendMessage({
    platform: A.platform, conv_id: m[1], url: location.href,
    title: document.title, text, hash, captured_at: new Date().toISOString()
  });
}

new MutationObserver(() => { clearTimeout(timer); timer = setTimeout(flush, 20000); })
  .observe(document.body, { childList: true, subtree: true, characterData: true });
document.addEventListener("visibilitychange", () => { if (document.hidden) flush(); });
// bg.js — 送不出去就排隊，每 5 分鐘重試
const ENDPOINT = "https://ideas.YOUR-DOMAIN/ingest";
const TOKEN = "長亂數字串";

chrome.runtime.onMessage.addListener(p => enqueue(p));

async function enqueue(p) {
  const { q = [] } = await chrome.storage.local.get("q");
  const rest = q.filter(x => !(x.platform === p.platform && x.conv_id === p.conv_id));
  rest.push(p);                       // 同一對話只留最新版
  await chrome.storage.local.set({ q: rest });
  drain();
}

async function drain() {
  const { q = [] } = await chrome.storage.local.get("q");
  const left = [];
  for (const p of q) {
    try {
      const r = await fetch(ENDPOINT, { method: "POST",
        headers: { "Content-Type": "application/json", "Authorization": "Bearer " + TOKEN },
        body: JSON.stringify(p) });
      if (!r.ok) left.push(p);
    } catch { left.push(p); }
  }
  await chrome.storage.local.set({ q: left });
}

chrome.alarms.create("drain", { periodInMinutes: 5 });
chrome.alarms.onAlarm.addListener(drain);

Fetch 放在 background 而不是 content script，是為了避開各平台頁面的 CORS／CSP 限制。

4.2 Collector（Mac Mini，Docker）

# collector.py
from fastapi import FastAPI, Header, HTTPException
from pydantic import BaseModel
import sqlite3, os, datetime as dt

TOKEN = os.environ["IDEA_TOKEN"]
db = sqlite3.connect("/data/ledger.db", check_same_thread=False)
db.executescript("""
CREATE TABLE IF NOT EXISTS conv(platform TEXT, conv_id TEXT, url TEXT, title TEXT,
  text TEXT, hash TEXT, first_seen TEXT, last_capture TEXT, dirty INT,
  PRIMARY KEY(platform, conv_id));
CREATE TABLE IF NOT EXISTS visit(platform TEXT, conv_id TEXT, day TEXT, at TEXT,
  PRIMARY KEY(platform, conv_id, day));
""")

class Capture(BaseModel):
    platform: str; conv_id: str; url: str; title: str
    text: str; hash: str; captured_at: str

app = FastAPI()

@app.post("/ingest")
def ingest(c: Capture, authorization: str = Header("")):
    if authorization != f"Bearer {TOKEN}":
        raise HTTPException(401)
    now = dt.datetime.now().isoformat(timespec="seconds")
    db.execute("""INSERT INTO conv VALUES(?,?,?,?,?,?,?,?,1)
      ON CONFLICT(platform, conv_id) DO UPDATE SET
        url=excluded.url, title=excluded.title, text=excluded.text,
        hash=excluded.hash, last_capture=excluded.last_capture, dirty=1
      WHERE conv.hash != excluded.hash""",
      (c.platform, c.conv_id, c.url, c.title, c.text, c.hash, now, now))
    db.execute("INSERT OR IGNORE INTO visit VALUES(?,?,?,?)",
      (c.platform, c.conv_id, now[:10], now))
    db.commit()
    return {"ok": True}

4.3 Summarizer（launchd 每 5 分鐘）

  1. 取 dirty=1 且 last_capture 早於 15 分鐘前的對話。
  2. 經 LiteLLM Gateway 呼叫本地模型（24GB 記憶體建議 14B 級、32K context）。
  3. 長對話：沿用上一版摘要 + 只送新增部分（以 hash 前後差異切），避免超出 context。
  4. 依 JSON 結果覆寫卡片、更新當日日誌，設 dirty=0。
系統提示：
你是想法整理員。以下是一段 {platform} 對話的頁面文字（含介面雜訊，請忽略）。
用繁體中文輸出 JSON，不要其他文字：
{
  "title": "15 字內標題",
  "summary": "3 句內摘要",
  "ideas": [{"type": "新想法|延伸|待驗證", "idea": "...", "next_step": "..."}],
  "decisions": ["..."],
  "projects": ["從清單選：換電站EMS, 微電網, 電池, 數位人類, AI OS,
               InMoov, Amazing Hand, 可信任的控制, 本地LLM/CoPartner, 其他"]
}
若對話只是查資料、沒有任何想法或決策，ideas 與 decisions 給空陣列。

5. 一次性設定步驟（約半天）

  1. Vault：在 iCloud Drive 建 Obsidian vault，內含 Ideas/，掛載進 collector 容器。
  2. 服務：docker compose up -d 跑 collector；launchd 註冊 summarizer。
  3. 對外：用 Cloudflare Tunnel 把 collector 暴露成 https://ideas.你的網域（公司或外出都能送）；只在家用可直接打 192.168.1.237。
  4. 擴充：每台電腦的瀏覽器以「載入未封裝項目」安裝一次，填入 endpoint 與 token。
  5. 回填：ChatGPT、Claude 各匯出一次歷史資料，用同一個 summarizer 批次處理，建立過去的想法庫。
  6. 驗收：三個平台各開一段對話，20 分鐘內應出現卡片與日誌。

6. 已知限制與對策

限制對策
手機 App 的對話抓不到之後在電腦打開那段對話即自動補抓；或用附錄的「記一下」指令先在手機產出卡片
Claude／ChatGPT 桌面 App 抓不到改用瀏覽器分頁
公司 Windows 可能禁止開發者模式擴充先試；被擋就只在 Mac 上用，公司機的對話靠回家後在 Mac 開一次
Kimi 網址規則未驗證驗收時確認 /chat/<id> 格式，不符就改 adapter 一行
全量擷取會收到敏感內容摘要在本機；臨時對話自動略過；訊息含 #nolog 即排除

附錄：手機補強指令（選用，非無痕）

貼到 ChatGPT「自訂指令」、Claude「個人偏好」、Kimi 對應設定。平常不觸發，只有你說「記一下」才輸出，所以不會干擾一般對話。

當我說「記一下」時，把目前對話整理成以下格式並只輸出這段：

標題：

決策：
專案：
