收工流程。用繁體中文回覆，保持簡短。

1. 執行 `make test`，記下結果。
2. 逐項對照目前工單的「驗收」清單，在工單檔中勾選已達成的項目。
   - 全部達成 → ROADMAP 狀態改 ✅。
   - 未全部達成 → 維持 🟡，在工單檔末尾加「剩餘」小節，列出還差什麼。
3. 在 `docs/plan/PROGRESS.md`「工作紀錄」**最上方**新增一筆：
   ```
   ### YYYY-MM-DD · Txx 工單名稱
   - 完成：
   - 學到：（例如平台介面的意外行為、設計需要修正之處；沒有就省略）
   - 剩餘：（沒有就省略）
   ```
4. 更新 PROGRESS「下一步」：分別寫出下一張 ☁️ 工單與下一張 🖥 工單（沒有就寫「無」），並確認依賴已滿足。
5. 若這次發現設計需要改變，同步更新 `CLAUDE.md` 或設計文件，並在紀錄中註明。
6. Commit，訊息以工單 ID 開頭（例如 `T03: collector v2 endpoints`），push 到 `main`。
7. 用 3 行以內告訴 George：完成了什麼、測試結果、下一步是什麼（若需要他動手要特別標明）。
